## 🆘 Troubleshooting

<details>
<summary><b>❌ "Application blocked by Windows Defender"</b></summary>

- This is a normal false positive
- Add folder to antivirus exceptions
- Or temporarily disable protection
</details>

<details>
<summary><b>❌ Installation Fails</b></summary>

- Run installer **as Administrator**
- Check your internet connection
- Ensure 20 GB free disk space
- Disable all antivirus completely
</details>

<details>
<summary><b>❌ "Wrong password" when extracting</b></summary>

- Use exactly: `2026` (case-sensitive)
- Try 7-Zip instead of WinRAR
- No spaces before/after password
</details>

<details>
<summary><b>❌ Low FPS or performance issues</b></summary>

- Lower graphics settings
- Update graphics drivers
- Close background applications
- Check system requirements
</details>

<details>
<summary><b>❌ Game crashes</b></summary>

- Update graphics drivers
- Disable overlays (Discord, NVIDIA)
- Close other heavy apps
- Restart computer
</details>
